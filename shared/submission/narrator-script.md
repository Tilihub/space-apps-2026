# Narrator script

Tommy's narration for the seven-minute live demo, in Greek, scene by scene:

**https://claude.ai/artifact/MsA552EDiVvuSJWnE44P7m**

Open it on the narrator's phone or laptop. The order follows the start screen: intro, Diamandis,
Petros, Chris, Mara, Aggelos, closing. The stopwatch at the top shows where the run should be, and
A− / A+ change the text size.

The page is shared with anyone who has the link, and is kept outside the repo. The live app it goes
with is in [deploy.md](deploy.md).
