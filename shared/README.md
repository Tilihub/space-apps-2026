# Shared

Everything the whole team needs, not tied to one person:

- [`PLAN.md`](PLAN.md): the idea, scope, who does what, timeline
- [`decisions/`](decisions/): one file per team decision
- [`sources.md`](sources.md): every source we use (the submission needs this list)
- [`research/`](research/): research notes
- [`submission/`](submission/): the Space Apps project page draft and checklist
- [`reports.md`](reports.md): problems with git, GitHub or the repo's setup, and structure changes, for zt and Tommy
- Data files the team uses: add a `data/` folder when you need one

Anyone can add files. Ask before changing a file someone else made.
Keep each file under 50 MB; GitHub refuses anything over 100 MB.
