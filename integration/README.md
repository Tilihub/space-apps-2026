# Integration

Where pieces from `people/` get joined and tested before anything goes into `final/`.

- One folder per connection, for example `integration/app-cabinet/`.
- Each folder starts with a short `README.md`: what it joins, which people's work it uses,
  how to run it, and whether it works yet.
- Rough test versions are fine here. Only what works moves on to `final/`.
- Whoever is doing a connection edits its folder; others ask first.
