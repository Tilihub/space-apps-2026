# People

One folder per person, named with the name they chose at onboarding: `people/<name>/`.

Put anything you're working on in your folder: experiments, drafts, notes, code. Only you edit it.
To use someone else's work, copy what you need into your own folder or into `integration/`.

Each folder has a `status.md`, copied from [`_template/status.md`](_template/status.md). It says what
you're doing and where you left off, so anyone can continue your work if you leave.

Each folder also has a `plan.md` for your own planning: your part, your tasks, and ideas for the team.
To get an idea into the common plan, propose it as a change to `shared/PLAN.md`.
